# Alexandru Ene - My Resume as A Web Developer

## Description

This is my personal portfolio web page showcasing my work and my skills as a web developer. Built with Next.js.

## Live Demo

Take a look here: [Live Demo](alexandru-ene-dev-portfolio.vercel.app)

## Features

- Projects showcase with live demo and GitHub links
- Downloadable resume
- UX friendly
- Responsive design for mobile and desktop
- Blog section
- Light/dark theme

## Technologies Used

- **Design**: Figma
- **Framework**: Next.js
- **Styles**: Tailwindcss
- **Deployment**: Vercel

## Installation

# Clone the repo
git clone https://github.com/alexandru-ene-dev/my-portfolio-website

# Navigate into the folder
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
